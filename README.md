# Kabricks HTML #

> :warning: **Important Update**: The `kabrick/html` package has replaced the `laravelcollective/html` package. Please replace all references of `Collective\Html` in your project with `Kabrick\Html`. For the majority of applications, no other changes should be necessary, and your project should continue to work as expected. However, always ensure to thoroughly test your project after this update to avoid unexpected issues. Thank you for your understanding.
